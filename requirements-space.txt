# Runtime deps for the Hugging Face Space (Streamlit viewer only).
#
# Deliberately smaller than requirements.txt. The app imports only src.config
# (yaml) and src.backtest.metrics (numpy/pandas), and reads pre-computed
# parquets from data/processed — the Space never fetches data, never runs a
# backtest, and never calls an LLM. So databento, anthropic, openai, pypdf,
# jupyter and the test tooling are all omitted; shipping them would inflate the
# image for code that cannot execute here.
#
# Ceilings are set above the majors this project currently resolves to
# (plotly 7.x, pandas 3.x) — NOT below them. A <7.0 plotly or <3.0 pandas
# cap fails the Space build immediately.
# Keep the shared pins in sync with requirements.txt. If a page starts importing
# a pipeline module, add its deps HERE too or the Space builds fine and then
# fails at runtime on that page.

pandas>=2.0,<4.0
numpy>=1.24,<3.0
pyarrow>=15.0,<22.0            # parquet engine for pd.read_parquet

streamlit>=1.30,<2.0
plotly>=5.18,<8.0

pyyaml>=6.0,<7.0              # src/config.load_config
